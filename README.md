# Pradhyumna Raj.B - Personal Portfolio

A clean, single-page developer portfolio showcasing skills, projects, and contact information. Built with semantic HTML5 and modern CSS, using CSS Variables for theming, Flexbox for layout alignment, and CSS Grid for responsive project displays.

## Features

* **Semantic Structure:** Built using HTML5 structural elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
* **Design & Typography:** Uses a custom CSS variable design system (`--brand`, `--ink`, `--bg`, `--surface`, `--border`) with system font fallbacks.
* **Flexbox Layouts:** Applied to the header navigation bar and footer contact links for alignment.
* **CSS Grid & Media Queries:** Responsive multi-column layout for the projects section (`1 column` on mobile, `2 columns` at `640px`, `3 columns` at `900px`).
* **Responsive Media:** Fluid image styles using `max-width: 100%` and `height: auto`.

## Built With

* **HTML5**
* **CSS3** (Flexbox, CSS Grid, Custom Properties/Variables)
* **Python** (Core Skill set)

## Project Setup

1. Clone or download the repository to your local machine.
2. Open `index.html` in any modern web browser to view the page locally.
